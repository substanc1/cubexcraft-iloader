# Безопасность / Security

Установщик работает с вашим Apple ID и устройством. Нашли уязвимость — не публикуйте её в issues. Сообщите приватно:
GitHub → вкладка **Security** → **Report a vulnerability**, или письмом на admin@cubexcraft.site.

The installer works with your Apple ID and device. Found a vulnerability? Please report it privately via GitHub →
**Security** → **Report a vulnerability**, or email admin@cubexcraft.site. Do not post it in issues.

Официальные сборки — только с https://www.cubexcraft.site. Official builds come only from https://www.cubexcraft.site.
